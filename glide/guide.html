Glide 1.4

Glide Installation Guide

Everything you need to turn your phone into a trackpad, keyboard and remote for your laptop, from a fresh computer to a working wired connection.

Part 1LaptopInstall Python, then start the Glide server.
Part 2PhoneInstall the Android app, or use any phone's browser.
Part 3Cable (optional)Connect over USB-C instead of Wi-Fi.

About 10 minutes the first time. After that, start Glide on the laptop and open the app.

Part 0

Before you start

  • A laptop or desktop running Windows 10/11, macOS 11 or newer, or Linux with an X11 session.
  • A phone. Android 7 or newer for the Glide app. Any iPhone or Android phone works through the browser.
  • A connection between them: the same Wi-Fi network, or a USB-C data cable. Some cheap cables only charge.
  • Internet once on the laptop, to download Glide and its two small Python libraries.

HDMI won't work. HDMI only carries video out of the laptop, and phones have no HDMI input, so touches can't travel back over it. Use Wi-Fi or a USB-C cable.

Part 1

Set up the laptop

Pick your laptop's system. The steps below change to match.

Install Python

On Windows you can skip this. If Python is missing, start.bat installs it for you. Install it yourself only if start.bat asks you to.

  1. Go to python.org/downloads and download the latest Python 3 for Windows.

  2. Run the installer. On the first screen, tick “Add python.exe to PATH” before clicking Install Now. This is the step people most often miss.

  3. Prefer the command line? This does the same thing in PowerShell:

    winget install Python.Python.3.12

  1. Download the macOS installer from python.org/downloads and run it.

  2. Or, if you use Homebrew:

    brew install python

  1. Most distributions already ship Python 3. Make sure the virtual-environment module is there too (Ubuntu/Debian):

    sudo apt install python3 python3-venv

Quickest way: one command

This downloads Glide, installs Python if needed, adds a Glide icon to your desktop and starts it.

  1. Press the Windows key, type PowerShell and press Enter.

  2. Copy this line, right-click inside the PowerShell window to paste it, and press Enter:

    irm https://raw.githubusercontent.com/venkateshwaryamki-bot/venkateshwaryamki-bot.github.io/main/glide/install.ps1 | iex

  3. When it says Installed, a Glide window opens. Next time, just double-click the Glide icon on your desktop.

Prefer to do it by hand? Follow the steps below instead.

Download Glide

  1. Download the project as a ZIP:

    https://github.com/venkateshwaryamki-bot/venkateshwaryamki-bot.github.io/archive/refs/heads/main.zip

  2. Unzip it first. Right-click the ZIP → Extract All… (Mac: double-click it). Put the result somewhere permanent, such as Documents. Everything you need is in the glide folder inside.

    Don't run anything from inside the ZIP. Windows lets you open a ZIP and double-click files in it, but Glide can't find its files that way.

Start Glide

  1. Open the glide folder and double-click start.bat. A black window opens. The first time, it may install Python and Glide's libraries, which takes a few minutes. If something goes wrong, the window stays open and says what to do.

  2. If Windows SmartScreen says “Windows protected your PC”, click More info → Run anyway.

  3. When Windows Defender Firewall asks about Python, tick Private networks and click Allow access. Without this, your phone can't reach the laptop.

  1. In the glide folder, right-click start.command → Open, then click Open in the warning. A plain double-click is blocked the first time because the file is downloaded and unsigned.

  2. If macOS says the file can't be run, open Terminal and run it directly. Drag the glide folder into the Terminal window after typing cd to fill in its path:

    cd ~/Documents/venkateshwaryamki-bot.github.io-main/glide
bash start.sh

  3. Allow mouse control. Open System Settings › Privacy & Security › Accessibility and switch on Terminal (use + to add it if it isn't listed). Then close the Glide window and start it again.

    Skip this and everything looks connected, but the pointer won't move. macOS silently ignores the input.

  1. In a terminal, from the glide folder:

    ./start.sh

  2. You need an X11 session. Wayland blocks programs from moving the pointer. On Ubuntu, pick Ubuntu on Xorg from the gear icon on the login screen.

It's working when a terminal window shows a QR code and Listening on port 8765, and a Glide pairing page opens in your browser with the same QR code. Keep that window open while you use Glide. The first start takes a minute while it installs its libraries.

Part 2

Set up the phone

Two ways in. The Android app adds auto-discovery, cable support, sharper haptics and keeps the screen awake. The browser version works on any phone with nothing to install.

Android app RecommendedInstall Glide.apk once. Finds your laptop by itself and works over a cable. Phone browseriPhone or Android. Scan the QR code and add Glide to your home screen.

Android app

  1. Get Glide.apk onto the phone. It's in the glide folder you downloaded. The easiest ways:

    • On the phone, open venkateshwaryamki-bot.github.io/glide and tap Download for Android.
    • Or copy Glide.apk over with a cable, Google Drive, or by emailing it to yourself.

  2. Tap the downloaded file. Android asks to allow installs from that app (Chrome or Files): turn on Allow from this source, go back, and tap Install.

  3. If Google Play Protect warns about an unknown app, tap More details → Install anyway. Glide is a personal app that isn't on the Play Store, so this is expected.

  4. Open Glide and tap Scan QR code. Allow camera access and point it at the QR code on your laptop. It connects within a second.

    If the camera won't scan, copy the link under the QR code on the laptop's pairing page and paste it into the box below the scan button.

You pair once. After that, opening the app reconnects on its own, even if your laptop gets a new Wi-Fi address. Tap the status pill at the top of the trackpad to switch between computers.

Phone browser (iPhone and Android)

  1. Open the phone's camera, point it at the QR code on the laptop, and tap the link that appears. Or type the address shown under the QR code into the browser.

  2. For a full-screen app icon:

    iPhone (Safari): Share → Add to Home Screen.
    Android (Chrome): ⋮ menu → Add to Home screen.

  3. Keep the phone from locking while you work: browsers can't hold the screen awake the way the app does. Set a longer Auto-Lock or Screen timeout in the phone's settings.

Part 3

Wired: USB-C cable

Optional. A cable gives you a connection that doesn't depend on Wi-Fi at all. There are two methods. USB debugging is faster; tethering needs no developer settings.

Method A: USB debugging (Android, fastest)

  1. Unlock Developer options: open Settings › About phone and tap Build number seven times until it says you're a developer.

    Where Build number is on Samsung, Xiaomi and others

    Samsung: Settings › About phone › Software information › Build number.

    Xiaomi / Redmi / POCO: Settings › About phone › tap MIUI / HyperOS version seven times.

    OnePlus / Oppo / Realme: Settings › About device › Version › Build number.

    Pixel / Motorola / Nokia: Settings › About phone › Build number.

  2. Open Settings › System › Developer options and turn on USB debugging.

  3. Start Glide on the laptop. The first time, it downloads Google's official adb tool (about 7 MB) into the glide folder. It only needs to do this once.

  4. Plug the phone into the laptop. On the phone, tap Allow on “Allow USB debugging?” and tick Always allow from this computer.

  5. Open the Glide app. It pairs over the cable by itself (no QR code needed) and the status pill shows a USB badge. The laptop terminal says USB cable … linked.

Unplug the cable and the app moves to Wi-Fi by itself. Plug it back in and it switches back to the cable.

Windows: if the phone never shows the “Allow USB debugging” prompt, it probably needs its maker's USB driver. Samsung phones need the Samsung Android USB Driver, and Pixels need the Google USB Driver. Install it, unplug the phone, and plug it in again.

Glide finds an existing adb automatically (Android Studio, Homebrew's android-platform-tools, or one on your PATH) and only downloads its own copy if none is found.

In a phone browser instead of the app (USB debugging still on), open http://localhost:8765 while the cable is plugged in.

Method B: USB tethering (no developer settings)

  1. Start Glide on the laptop and plug in the cable.

  2. On the phone: Settings › Network & internet › Hotspot & tethering → turn on USB tethering.

  3. Open the Glide app. It finds the laptop over the cable network by itself. If you've never paired, scan the QR code once.

Watch your data plan. With tethering on, the laptop may use the phone's mobile data for internet. Turn mobile data off on the phone if you don't want that.

iPhone over a cable

Turn on Settings › Personal Hotspot › Allow Others to Join, then connect the cable. On Windows this needs Apple Devices or iTunes installed.

Turn the laptop's Wi-Fi off and restart Glide so the QR code uses the cable network, then scan it with the iPhone camera.

Part 5

Troubleshooting

ProblemFix
Phone stuck on “Connecting…” or “Can't reach computer”Check both devices are on the same Wi-Fi (not a guest network, which often blocks devices from seeing each other). On Windows, allow Python through the firewall on Private networks. Turn off any VPN on either device.
Connected, but the pointer doesn't move (Mac)Give Terminal Accessibility permission (Part 1), then restart Glide.
Connected, but the pointer doesn't move (Linux)You're on Wayland. Log in with an X11 / Xorg session.
“python is not recognized” (Windows)Reinstall Python with Add python.exe to PATH ticked, then run start.bat again.
“Port 8765 is busy”Another Glide is still running: close it. Or start on another port with start.bat --port 8766 (Mac/Linux: ./start.sh --port 8766).
QR code won't scanCopy the link under the QR code on the laptop's pairing page and paste it into the app, or type it into the phone's browser. Brightening the laptop screen helps too.
Laptop doesn't appear in the app's listTap the refresh button. Windows firewall can block discovery even when the QR code works, so pair by QR once. After that the app reconnects on its own.
Cable plugged in, nothing happensUse a data cable (charge-only cables are common). Make sure USB debugging is on and you tapped Allow. On Windows, install the phone maker's USB driver.
“Couldn't download adb”The laptop was offline or the download was blocked. Install it yourself, then start Glide again: winget install Google.PlatformTools (Windows) or brew install android-platform-tools (Mac).
Android app won't install over an old versionThe old copy was signed with a different key. Uninstall Glide from the phone, then install again.
Pointer feels too slow or fastSettings → Pointer speed and Acceleration. Settings are saved on the phone.

Part 6

Update or remove

Update

Download the latest ZIP and replace the old glide folder. Your pairing is kept, because the key lives in your home folder, not in glide. Install the new Glide.apk over the old one; paired computers carry over.

Unpair every phone

Start Glide once with a new pairing key, then scan the new QR code on the phones you want to keep:

start.bat --new-key
./start.sh --new-key

Remove Glide

Delete the glide folder and the hidden .glide folder in your home directory (it holds the pairing key). Uninstall the app from the phone like any other app.

All start-up options

OptionWhat it does
--port 8766Listen on another port
--host 192.168.1.20Put a specific IP address in the QR code
--new-keyMake a new pairing key (unpairs all phones)
--no-browserDon't open the pairing page
--no-usbTurn off USB-cable mode
--no-adb-downloadNever download adb automatically
--adb PATHUse a specific adb program

Privacy: Glide talks only to devices on your network or cable. Nothing goes to the internet. Only phones with your pairing key can connect, so only scan the QR code on your own devices, and use Glide on networks you trust.
